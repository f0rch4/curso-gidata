# Descripción del proyecto
Durante esta fase del proyecto se define la estructura y almacenamiento de datos históricos de los mundiales de la FIFA. Consiste en el diseño e implementación de una base de datos que garantiza la integridad de los mismos, y normalización de la información, donde abarca desde jugadores, goleadores, equipos, hasta estadios, sedes y ganadores.

## Tecnologías utilizadas
Motor de base de datos: MySQL(XAMPP)
Gestor de base de datos: phpMyAdmin   
Lenguaje: SQL

## Instrucciones de ejecución
1. Tener instalado cualquier servidor MySQL.
2. Iniciar los servicios de Apache y MySQL.
3. Abrir phpMyAdmin. 
4. Crear una nueva base de datos vacía llamada `copamundo`.
5. Importar el archivo `copamundo.sql` proporcionado en este repositorio.
